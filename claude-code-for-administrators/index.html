Under the Hood

Why the command line?

Two ways to tell a computer what to do. One was built for us; the other is the direct line to the machine.

The GUI — what you click
  • Windows, buttons, a mouse to drag and point
  • Built for humans; every action is a click someone makes
  • To automate it, software has to fake a mouse hunting for buttons
The CLI — what you type
  • Typed commands in the terminal, a thin text layer over the OS
  • Closer to the machine, and the layer software actually automates
  • An AI agent types the same commands a programmer would
This is the leap PCs made going from MS-DOS to Windows in the early '90s: typed commands gave way to clicking, because clicking was easier for people. Claude Code brings the direct, typed control back, no faked mouse clicks, and now you drive it in plain English.

Before We Go Further

Is it safe? Two controls do the work.

The tool is permission-gated and runs on my own machine, so nothing happens without my say-so. But what actually keeps district data safe is two things I do, not something the tool does for me.

I use a paid business account
  • Business-tier usage is not used to train the model
  • The risky version is a personal, free account
  • Staff should never use personal logins for district work
I de-identify before it goes in
  • No student names, no PII
  • I work with counts and role labels
  • Sensitive data gets stripped before the tool ever sees it

Purchasing

Five vendor bids in.
One scored matrix out.

Drop the proposal PDFs in, name the criteria, and Claude Code reads every bid, pulls the numbers, and lines them up in a single comparison, scored and ready to defend. Copy paper to E-Rate.

Hiring

A stack of applications to a ranked shortlist.

For an open role, Claude Code reads every application against the minimum qualifications, flags who meets them, and ranks the field on a rubric I set. Hours of screening, done before the first interview.

Aggregates and rubric scores only. No applicant names leave the room.

And it all lives in Obsidian.

Every session, memo, and analysis Claude Code runs gets logged here and linked. Hundreds of connected notes — the institutional memory our whole operation runs on.
In AI terms this is a RAG — retrieval-augmented generation. Plain version: before it answers, Claude Code searches this vault and pulls in what's relevant, so it reasons from our real history instead of guessing.
